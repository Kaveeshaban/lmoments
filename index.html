L-Moments River Analysis

A C++ program that fits the Pearson type III distribution to river discharge series by the method of L-moments. This page documents the method and the code, and runs the same calculation in the browser.

Overview

The program reads discharge series for several rivers or gauging stations and describes each series with L-moments. From the L-moment ratios it derives the three parameters of a Pearson type III distribution, reports conventional statistics (mean, standard deviation, Cv, Cs) and assigns a simple flood-risk class from the L-coefficient of variation.

It needs two plain text files. The names file holds one river and station per line. The data file holds only numbers, one column per river, in the same order as the names.

Names file (rivers.txt)

P.Sheltozerka - S.Sheltozero
Lososinka - R.Lososinka - G.Petrozavodsk
Neglinka - R.Neglinka - G.Petrozavodsk

Data file (data.txt)

1.31 6.02 0.72
1.45 5.06 0.70
1.05 4.14 0.47

Both examples come from the program's own help text. Spaces or tabs separate the columns, and a comma is accepted as the decimal sign.

For every river with at least four values the program reports

  • L-moments l1 to l4 and the ratios t2 (L-Cv), t3 (L-skew) and t4 (L-kurtosis)
  • probability-weighted moments b0 to b3
  • Pearson III shape α, scale β and location γ
  • mean, standard deviation, Cv and Cs
  • a flood-risk class: LOW, MODERATE or HIGH

Build and run

g++ -O2 -o lmoments lmoments.cpp
./lmoments

The program then asks for the names file, the data file and a name for the results file. With Microsoft Visual C++, define _USE_MATH_DEFINES before including <cmath> so that M_PI is available.

How it works

The program runs in seven steps. The line numbers point into the source listing at the bottom of the page; select one to jump there.

  1. Read the river names

    One name per line. Carriage returns are removed and blank lines are skipped.

  2. Read the discharge data

    Whitespace-separated columns. Commas are read as decimal points and values of zero or below are dropped. The first line fixes the number of columns.

  3. Create one River object per column

    Columns with fewer than four values are skipped with a warning. Each River keeps a sorted copy of its series, in ascending order.

  4. Compute the probability-weighted moments

    One pass over the sorted series gives b0 to b3.

  5. Compute the L-moments and L-moment ratios

    l1 to l4 are linear combinations of the b values. Dividing gives t2, t3 and t4.

  6. Estimate the Pearson III parameters

    The shape α comes from a rational approximation in t3. Scale β and location γ follow from l1, l2 and α.

  7. Report the results

    Each river is printed to the console, followed by a summary table. The same blocks and a summary table are written to the results file.

Method

The sorted series is x1 ≤ x2 ≤ … ≤ xn, and sums run over j = 1 … n. The source writes l and t where the formulas use λ and τ.

Probability-weighted moments
b0 = 1n Σ xj
b1 = 1n Σ j − 1n − 1 xj
b2 = 1n Σ (j − 1)(j − 2)(n − 1)(n − 2) xj
b3 = 1n Σ (j − 1)(j − 2)(j − 3)(n − 1)(n − 2)(n − 3) xj
L-moments
λ1 = b0
λ2 = 2b1 − b0
λ3 = 6b2 − 6b1 + b0
λ4 = 20b3 − 30b2 + 12b1 − b0
L-moment ratios
τ2 = λ2λ1 (L-Cv),   τ3 = λ3λ2 (L-skew),   τ4 = λ4λ2 (L-kurtosis)
Shape α, for |τ3| < 1/3
z = 3πτ32
α = 1 + 0.2906zz + 0.1882z2 + 0.0442z3
Shape α, for 1/3 ≤ |τ3| < 1
z = 1 − |τ3|
α = 0.36067z − 0.59567z2 + 0.25361z31 − 2.78861z + 2.56096z2 − 0.77045z3
Limits on α
|τ3| < 10−6 gives α = 1000, and |τ3| ≥ 1 gives α = 0.01.
The result is then clamped to 0.01 ≤ α ≤ 200.
Scale β
β = λ2 √π Γ(α)Γ(α + ½)
Location γ
γ = λ1 − αβ
Conventional statistics
σ = β√α,   mean = γ + αβ,   Cv = σmean,   Cs = 2√α
Flood-risk class
τ2 < 0.2: LOW,   τ2 < 0.5: MODERATE,   otherwise HIGH
